# Retro Amp Radio

I need fully functional old style WinAmp design music player . It needs to use only free resources , so I don’t pay for cloud etc. I attached photo for the reference on how it should look like. Would be good if it could fetch live radio stations from worldwide so I could pick country and play radio live. I’m sure you can find reliable resources list to pull the signals from , GitHub is full of them.
