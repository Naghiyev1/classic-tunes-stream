# Favourites

## What will change
- Add a small star control to every station row without changing the player’s size or visual style.
- Add a compact `ALL / FAV` selector above the station list, including the saved count.
- Let people play, search, and remove stations from the favourites view.
- Save favourites on the current device, with no account, cloud service, or cost.

## Technical details
- Persist complete station records in browser storage so favourites remain available when switching countries or reopening the player.
- Keep the existing free radio directory, playback controls, themes, and responsive layout unchanged.
- Verify saving, filtering, playback, empty state, mobile fit, and theme compatibility in the live preview.
